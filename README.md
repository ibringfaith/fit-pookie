# Fit Pookie

Fit Pookie's name is derived from two words: "fit" and "pokie." Fit is short for outfit, and pokie is short for poker machine or... slot machine. Our love for fashion and gaming inspired the creation of this website.

Fit Pookie is a website where users can upload images of their clothes into a digital closet, view pixelated versions of their clothes, and generate randomized outfits using a slot machine. Users can also save their favorite generated outfits to a gallery page.

This project is built using **React** and **Tailwind CSS** and is currently in its early development phase.

### Planned Features
- Users can upload images of their clothing to their closet.
- The uploaded image will be shown in a pixel style.
- Users can navigate to the slot machine page to generate outfit ideas
- Users can choose to save the generated outfit to their gallery page

### Current Features
- Welcome screen
- Slot machine screen
- Navigation between pages
